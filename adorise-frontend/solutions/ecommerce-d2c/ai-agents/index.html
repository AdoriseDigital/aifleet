Frequently Asked Questions

Can the AI agent look up live tracking information for customers?

Yes. The agent connects to your Shopify, ShipStation, or parcel tracking APIs to deliver real-time shipping milestones.

How does the agent handle complex return requests?

The agent verifies order eligibility against your written return policy, collects proof photos if required, and generates prepaid return shipping labels.

Will the agent ever invent unauthorized discount codes?

No. The agent operates under strict deterministic JSON function schemas with zero permission to generate unapproved coupon codes.

What helpdesk platforms are supported?

We support native integrations with Gorgias, Zendesk, Freshdesk, Intercom, and custom webhook-based helpdesk platforms.

What happens if a customer insists on speaking with a human?

The agent immediately flags the conversation, generates an executive summary of the issue, and routes the ticket to your human support team.
